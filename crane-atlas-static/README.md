# Crane Atlas — Static UI Demo

A faithful static UI representation of the retired Flask version of Crane Atlas.

This folder preserves the final visual language, page structure, navigation and representative interactions without running Flask, SQLite, authentication, email, uploads, or any production service.

- HTML
- Original Crane Atlas CSS + small static-demo overrides
- Vanilla JavaScript
- Representative dummy data

The original Crane Atlas application remains unchanged in its own repository.
